# Meet Landing Page

A responsive landing page built for a Frontend Mentor challenge using HTML and CSS.

## Overview

Meet is a landing page for a group video chat product. I built the layout for desktop, tablet, and mobile screens, focusing on responsive design and clear visual hierarchy.

## Features

- Responsive hero section with participant images
- Image gallery that adapts to screen size
- Responsive footer
- “What is it?” link that scrolls to the features section

## Built with

- Semantic HTML5
- CSS Grid and Flexbox
- CSS media queries
- Inter font

## Run locally

Clone the repository and open `index.html` in your browser. No installation or build step is required.

## What I learned

This project helped me practice arranging images and text with CSS Grid, changing the layout at different screen widths, and organizing HTML into meaningful sections.

## Note

The download buttons reproduce the challenge design. No downloadable application was provided with the challenge assets.
